Get Fishing Helper open
in three steps.

Use File Explorer to open the folder containing this page. The filenames below are the things to double-click.

1

Install once

Setup Fishing Helper.cmd

Watch the four setup steps. First-time installation needs internet. Success says SETUP COMPLETE.

If Python is missing, setup opens its official download page. Install Python 3.12, 64-bit, with Python Launcher and Tcl/Tk, then run Setup again.
2

Open the app

Start Targeting.cmd

Use this each time. If setup is missing, it runs setup first. No administrator account is normally needed.

3

Preview first

Mode: dry-run

This shows detections without moving or clicking. Follow the pictured controls below to select the game.

New: choose the window and bobber visually

  1. Choose the fishing template profile, then click Select game window. Choose your game. Its number and full capture area are filled in automatically.
  2. Click Open screenshot / select bobber to use a screenshot you already have. Or click Screenshot in 10s / select bobber, switch to the game and cast.
  3. Return to the helper after the countdown. Draw a tight box around your bobber on the frozen picture. There is no time limit.
  4. Click Save bobber template. Start preview in dry-run.

Neither screenshot option clicks in the game. Pause / Stop cancels a pending countdown. If the game is not in front when the countdown finishes, capture is rejected; you can try again or open a saved picture. Use full game area refreshes the recording area after moving/resizing the game.

Preview picture and detection/error reason appear here.

  1. Open World of Warcraft and keep it visible.
  2. Click Choose profile. Open configs/tasks/fishing-v1.json from this folder.
  3. Click Allowed windows / metadata. In the lower text area, find your game's entry under windows. Copy its numeric hwnd into the app's hwnd field. That number identifies this open game window; it can change after restarting the game.
  4. Keep mode on dry-run. Click Start preview, then bring the game to the front. Return to the helper to inspect its last picture and reason. Foreground capture pauses while the helper is in front.

A detector still needs reference images. The template profile expects bobber pictures in images. Those personal images are not shipped in Git. If they are missing, installation can succeed but detection cannot. Do not switch to live input to fix a missing-template error. A neural profile similarly needs an evaluated, approved model; setup does not create one.

Ignore the advanced fields for now

For a first preview you only need profile, hwnd, and dry-run. Leave registry at its default. Dataset, session, cast and region are for recording. Config, output, weights and training_run are for training/evaluation. Release and reviewer are for rollback. You do not need to fill them all in to launch.

Pause / Stop stops and disarms the preview. Cancel job stops a running recording/training/evaluation job. Closing the app stops both.

Before trying mouse input

Keep dry-run until the preview is correct. Verify movement in the local mouse test first (see the advanced documentation). Then move mode and Arm ONE attempt allow one movement test after a three-second countdown. Focus the selected target window during that countdown. single-click permits one click attempt per arm. It does not mean a fish was caught.

This targeting application currently supports preview, recording and one-shot action verification. It does not automatically cast and fish continuously. The installer does not enable the legacy fishing loop or automatically approve models.

If something goes wrong

  • Setup failed: rerun Setup; if it still fails, share data/setup.log.
  • No game listed: open the game, unminimize it, and check that the profile permits its window title and executable.
  • No preview: check the visible reason; focus the game. Missing templates or weights must be supplied first.
  • App will not open: rerun Setup to repair its private environment. Your datasets are not removed.
