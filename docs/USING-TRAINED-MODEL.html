Your model is trained. Here is how to try it.

Close the helper and reopen Start Fishing.cmd. Normal fishing remains available with the original template detector. No model is switched on automatically.

What the three modes do

ModeWhat happens
Neural candidate previewShows the detected bobber and proposed mouse point. Does not move or click. Works before model approval.
Evaluated movement-only testOne explicitly armed move to the point. Never clicks. Requires a matching completed independent test report, but can test a model that has not passed automatic-fishing quality thresholds.
Automatic neural fishingUses the approved neural detector in your original fishing loop. Acquires your new bobber, optionally hovers, waits for bite evidence, then issues one guarded right-click. Requires explicit approval and live-controls opt-in.

1. See what the neural network detects

  1. Open Visual targeting.
  2. Click Preview latest trained model (no input). The helper fills the trained .pt and profile paths, and reuses your normal fishing area when opened through Start Fishing.cmd. If more than one allowed game window exists, select your game and press the preview button again.
  3. Bring WoW to the front and manually cast.
  4. Watch the helper's picture for the cross on your bobber. On one monitor, Alt-Tab back to inspect the last picture. Capture pauses while the helper is foreground; this is expected. On two monitors you can keep the helper visible while WoW remains foreground.
  5. Check that the cross is on the float, not a reflection, another player's float or UI. Multiple qualifying bobbers cause abstention.
  6. Use Pause / Stop when done.

This button loads the candidate explicitly for preview. The ordinary Start preview button uses the configured profile/approved registry instead.

2. Let it move once, without clicking

  1. In Visual targeting click Set up movement-only test. A matching completed held-out evaluation is required.
  2. Focus WoW and let the preview show the bobber at the correct point. It must be one unambiguous fresh detection.
  3. Return to the helper and click Arm ONE attempt (3s).
  4. Switch to WoW within three seconds, release the mouse buttons and stop moving the mouse briefly.
  5. The helper attempts one move. It cannot click in this mode. Check whether your cursor becomes the gear over the bobber.
  6. Read Last attempt in the helper. Focus loss, stale pixels, moved/resized windows, held buttons, occlusion or user takeover reject the action. Re-arm only after correcting the reason.

Keep WoW on one monitor for the test. The system translates model boxes to the captured game crop and then physical desktop coordinates. It rechecks window geometry and actual mouse position; it does not apply the letterbox offset twice.

3. Understand and optionally calibrate the gear

The gear is a useful sign that the cursor is over an interactable object. It does not prove that a fish bit, and other interactable objects can also produce a gear. The tracker must still identify your newly cast bobber and observe a splash/bite before clicking.

  1. Open Normal fishing → Locations & Fishing, then scroll down to Detector and mouse placement.
  2. Click Use latest trained model paths to fill in the candidate and matching profile.
  3. For optional cursor confirmation, click 1. Capture normal cursor (5s), switch to WoW and hover empty water until the normal cursor is visible.
  4. Click 2. Capture gear cursor (5s), switch to WoW and hover your bobber until the gear is visible. Do not click.
  5. Check the calibration result. The two shapes must differ and be observed in the allowed game window.
  6. Turn on Require the calibrated gear cursor before a bite click if you want this extra condition. The helper skips a click if it cannot verify the calibrated gear.

Calibration lasts for this helper session. Recalibrate after relaunching the helper or game. If the game draws a software-only cursor that Windows reports as hidden, this calibration is unavailable; leave the optional gear requirement off. You can still inspect the gear manually during the movement-only test.

4. Read the evaluation before enabling automatic neural fishing

After each new training run, click Evaluate latest trained model (automatic paths) in Neural training and wait for completion. Then click Review evaluation / approve model in Visual targeting. It shows precision, recall, false detections per cast, and the configured thresholds. If the exact model passes, the button asks you to explicitly approve it. Training and preview never approve weights.

Current result at implementation: your latest model was tested on 95 independent test frames. Precision was 97.1%, recall 68.4%, and the report counted two false detections in the test cast. The profile requires at least 95% precision, 90% recall and at most 0.1 false detections/cast. It therefore is not approved for automatic fishing yet. Candidate preview and the explicitly armed movement-only test are available now. The application reads the latest matching report; these displayed values may change after retraining/re-evaluation.

To improve it, collect new independent examples resembling missed cases, review small bobbers and reflections consistently, and run a longer training configuration. Keep held-out frames out of training; do not copy test images into the training partition. Evaluate the resulting new best.pt with its own run metadata before approval. More training is not a guarantee of passing.

5. Turn on neural automatic fishing after approval

  1. Open Normal fishing → Locations & Fishing.
  2. Under Find bobbers using, choose Neural network (approved model for live).
  3. Click Use latest trained model paths. They must match the model you evaluated and approved. Live inference uses the immutable approved registry artifact, not an arbitrary unchecked .pt.
  4. Enable Move onto a uniquely tracked bobber while waiting for the bite if you want the pointer to hover as soon as ownership is established.
  5. Optionally calibrate and require the gear as described above. Save your settings.
  6. Return to Normal fishing → Start, check Enable live game controls, then click Start fishing.
  7. The normal loop casts, excludes pre-existing floats, confirms a unique new bobber across fresh frames, hovers if enabled, waits for temporal bite evidence, then moves to a fresh point and right-clicks once. Independent loot evidence is needed to record a confirmed catch.
  8. F9 pauses/resumes the fishing loop. Esc stops it. Pause / Stop controls the separate targeting preview.

To return to the original detector, select Template matching (original). An unapproved neural model cannot be used for automatic input; selecting the checkbox does not bypass evaluation. Leave live controls unchecked for dry-run decisions only; dry-run does not cast for you.

If it does not move

  • Missing or ambiguous: keep one bobber in the test view and inspect the detection cross. The model may miss small/low-confidence targets.
  • Not foreground: put WoW in front during the arming countdown.
  • Invalid transform / area outside game: repeat the window/area selection after moving or resizing WoW or changing UI scale.
  • Stale / processing stale: let the model finish its initial warmup; inspect processing time. Old detections are never dispatched.
  • Gear not confirmed: repeat both calibrations in the same game session, or turn off the optional requirement.
  • No promoted model / quality thresholds not met: use candidate preview or movement-only testing while improving and evaluating the detector.
  • Acquisition expired: inspect data/fishing-debug/acquisition-latest.json and its ROI picture. The log distinguishes missing, ambiguous, pre-existing and stale targets.

The last trained model is shown on Neural training; Open trained model folder takes you to best.pt. A .whl is only the application package.
